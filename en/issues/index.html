Work No Longer Teaches by Itself

AI helps a novice produce an expert-level result, but it can quietly remove the very practice from which an expert grows. Repetition does not save the model either: without memory, variation, and selection, more attempts merely produce more of the same. Learning is therefore becoming a separate production system. Elsewhere this week, mathematics showed where a good question is becoming more valuable, an image of a receipt lost its evidentiary force, and three microreactors moved through a fast lane for physical testing.

AI learns worse than humans—and can still win

A machine does not have to conserve every experience. In code and simulation, it turns mistakes into cheap practice and copies the learned skill without training another student. But in the physical world, the model is no longer the one paying for an error—and power returns to whoever controls the proving ground, integration, and outcome guarantee.
